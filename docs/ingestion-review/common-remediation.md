# Common-layer remediation

Working record, 2026-10-11. The [common scan](common.md) and [cross-layer traces](common-intersections.md) hold the original evidence. This record tracks changes made against every numbered finding, including the compatibility cases found during implementation.

## Implemented

1. **Relationship vocabulary:** Configured names and aliases now use the same normalization as observed relationship labels. New definitions reject collisions across canonical names, labels, and aliases. Compiled snapshots give canonical names precedence when replaying an older ambiguous value. Durable project reads accept those older values so a project can open and be repaired; an unchanged ambiguous value cannot be activated again. An older ambiguous label may resolve differently until its owner corrects the config. Tests cover strict candidates, legacy load, correction, and snapshot replay.
2. **Finite settings:** Spending limits, model prices, and the common-word frequency threshold now reject infinity and NaN at settings validation. Tests cover persisted settings input and finite controls. This closes the setting-level bypass; it does not measure model spending against a real provider.
3. **Domain activation:** An active runtime resolves and checks the selected VP-01 adapter before the domain store commits. If model loading fails, neither the durable version nor the live domain changes. Tests assert load/commit/install order and no commit on a missing or invalid adapter. Loading a heavy model can add latency before a later version or Context-section conflict rejects activation.
4. **Malformed JSON diagnostics:** `safe_json_loads()` logs the error category and location without copying raw input. A Loguru sink test passes private tool-argument text and asserts it is absent from warnings.
5. **Agent Brain:** New and full Brain writes enforce the total and section limits and unique required headings. Existing oversized or duplicate stored Brains remain readable through the read tools so they can be repaired; section edits and full writes remain strict. Tests cover specialist creation, read paths, snapshots, and rejected writes before storage.
6. **Document parser coordinates:** Source locators require finite bounding boxes. Docling projection omits invalid bounds and native PDF cells; its nested raw structure replaces non-finite values with `null`. The writer uses strict JSON serialization for snapshots, layouts, and embeddings before a transaction. Producer and writer tests assert clean payloads and no transaction for invalid values.
7. **Agent tool arguments:** The shared validator now enforces declared string patterns and finite numeric values. Tests use the actual entity-merge state-hash schema and relationship-conflict confidence schema.
8. **Failure-event privacy:** The coordination allowlist no longer accepts generic exception `error` or `reason` strings; the local-reference event retains its fixed reason code. Scheduler failure, preflight, timeout, monitor, and task-cleanup logs record exception types instead of message text or tracebacks. Tests capture both events and ordinary Loguru output containing a private-text exception.
9. **Older relationship prompt:** The dormant message-based relationship prompt now shows an empty result for co-location and an edge for an explicit shared action. Its offline token-fixture caller still loads it. A prompt-content check guards that distinction; this does not establish how a model will respond.

## Additional defect found while following the document path

The document embedding provider could return NaN, a malformed batch, or a malformed vector. The indexer previously checked only count and dimension, and malformed output could be treated as invalid document content. It now validates each provider batch and the complete vectors before storage and uses the bounded dependency-retry path. Tests assert the first retry, the terminal outcome after the attempt limit, and no partial publication when a later batch is malformed. The [general ingestion notes](general-ingestion.md) explain the existing retry policy.

The broad unit run also exposed an adjacent benchmark coverage defect. On Windows, the VP-01 benchmark cannot read POSIX peak RSS, yet one test required a value. Worse, a configured RSS regression gate silently passed when that metric was missing. The test now treats the metric as unavailable on Windows and the gate fails explicitly if a memory limit was configured without a measurement. This does not add Windows memory measurement.

It also exposed one real JEV rebuild defect and six stale assertions. The stale tests expected a name found only in a supporting message to become a Context entity, contrary to the established literal-in-block rule; they now assert a block-scoped unresolved issue and no JEV call. The real defect was that an exhausted observation budget prevented reconstruction of an unchanged, already accepted candidate on the second pass. A bounded replay lane now checks prior accepted block/name keys first and reuses a matching decision without another model call. Tests cover unchanged reuse behind a new earlier gap and invalidation when evidence or policy changes.

## Coverage and remaining limits

- Targeted tests exercise the boundary where each bad value or failure enters the system, plus its next durable or runtime effect. They are stronger than tests that only assert helper return values, but they remain mostly fake-backed.
- The document writer checks use a fake transaction cursor. A real PostgreSQL `jsonb` write with a sanitized Docling snapshot has not run in this pass; the local Docker daemon is unavailable.
- Real GLiNER/VP-01 loading, hosted extraction behavior, and agent model compliance with prompt wording have not been measured here. The active-runtime activation test uses a controlled adapter loader.
- An inactive project's domain activation writes storage directly and resolves its model on its next runtime bootstrap. The active-runtime preflight fix does not change that existing behavior.
- The scan listed several common utilities with no production caller found (`safe_update`, `BackgroundTaskGroup`, `cosine_similarity`, two legacy prompt formatters, and `extend_local_id_maps`). They are cleanup candidates, not demonstrated behavior defects. This pass leaves their interfaces in place; the offline token-fixture script also keeps its own legacy prompt formatters.
- The complete server unit suite passed **2,033 tests** with **2 skips** and three dependency deprecation warnings. The three architecture checks passed. The changed fake-backed document writer contract passed in its focused run, and `ruff check src tests scripts` plus `git diff --check` passed.
